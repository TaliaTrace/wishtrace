# WishTrace UX Skill

Read `docs/UX_RESEARCH.md`, `docs/DESIGN_SYSTEM.md`, `docs/SCREEN_MAP.md` and current screenshots.

Workflow:

1. Define the screen's one job.
2. Identify user uncertainty and money/trust concern.
3. Run Mobbin query if access works; never fabricate references.
4. Use AI images only for art direction.
5. Implement real Compose state.
6. Capture screenshot and silent interaction.
7. Test five-second comprehension, thumb reach, contrast, font scale and recovery.
8. Remove nonessential elements.

Avoid dark neon, generic AI gradients, chat-first UX, marketplace walls, fake progress and animation without meaning.

Output: purpose, references/status, hierarchy, trust issue, top fixes, screenshot evidence.
