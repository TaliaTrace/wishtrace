# WishTrace Design System

This is a starting system, not a prison. Freeze it by hour 8.

## Art direction

**A clear relationship planner with a modern gift-wrap finish.**

Qualities:

- bright;
- light;
- personal;
- scan-first;
- precise;
- trustworthy;
- not childish;
- not finance-heavy.

## Implemented color tokens

The July 30 UI reset uses a fixed WishTrace indigo/blue identity on cool white surfaces. Purple identifies the brand and primary action; state colors retain text and icons so meaning never depends on color alone.

```text
background        #F9FAFF
surface           #FFFFFF
surface-lavender  #F0EEFF
surface-blue      #EEF3FF
ink               #11142B
ink-muted         #5F647A
primary           #5B4BFF
primary-pressed   #4938E6
secondary-blue    #4878FF
success           #1E6B52
error             #A33A46
outline           #E2E5F0
```

Do not use a dark theme for Gold, dynamic system color, neon treatment or a gradient behind every card. Lavender and blue washes are reserved for welcome, empty and completion moments.

## Typography

Use Android system sans-serif for every role. No downloaded font is required.

Suggested scale:

```text
Display       36sp / 40sp, bold, onboarding only
Headline 1    28sp / 34sp, bold
Headline 2    22sp / 28sp, semibold
Title         18–20sp, semibold
Body          16sp / 24sp
Label         14–15sp, semibold
Caption       12sp, only when contrast remains strong
```

Never shrink text to fit generated mockups.

## Spacing

Use an 8dp base grid:

```text
4   micro alignment
8   compact internal spacing
12  related controls
16  standard card padding
24  section spacing
32  major separation
48  hero separation
```

## Shape

- Buttons: 16–20dp radius
- Cards: 20–28dp radius
- Chips: pill or 12–16dp radius
- Product images: 16–20dp radius
- Avoid every element being a floating rounded card

## Elevation

Use tonal separation and a 1dp cool outline before adding shadow. Payment and recommendation surfaces may receive slightly stronger elevation. Avoid glassmorphism.

## Icons

Use Material Symbols or a single coherent icon set. Brand logos must come from official assets and should not be generated by an image model.

The implemented WishTrace mark combines:

- a gift/wrapped object;
- a subtle path or trace;
- a short blue continuation stroke;
- no generic AI star/sparkle.

Three generated, transparent, non-product dimensional assets are allowed: a gift, calendar and message-heart. They may appear in emotional onboarding, empty and completion surfaces. They cannot represent a real candidate, merchant, receipt or transaction.

Onboarding compositions combine those focal assets with code-native supporting elements:

- orbit icon tiles for person/date/heart/trust;
- short floating badges;
- a five-day countdown rail;
- clue tokens and a saved-note card;
- selected/rejected candidate-category tiles;
- compact review fact tiles;
- a single trace line and restrained particle dots.

Supporting elements should explain the current moment or strengthen its emotion. They remain non-interactive unless semantics and behavior are explicitly provided.

## Motion grammar

Native Compose motion communicates state:

```text
objects float into attention
→ clue tokens collect
→ rejected choices recede
→ selected gift springs to center
→ review facts settle into a single card
```

Pager changes must remain interruptible. No animation blocks input or hides essential meaning. When Android animator duration is disabled, motion resolves immediately and the same information remains available through text, icons and semantics.

Discovery uses the same grammar continuously: clue bubbles move inward, a segmented trace ring advances, completed stage tiles switch to a check and the ready state changes to success color. Recommendation never uses an empty placeholder to imply a real product; the layered source-needed card is visually distinct from `RecommendationHero`.

## Copy style

Short, human and concrete.

Good:

- “Sophie's birthday is in 12 days”
- “Fits her gaming interest”
- “Arrives too late”
- “Approve $50 purchase”

Bad:

- “Our intelligent agent has generated an optimal recommendation”
- “Proceed to transaction orchestration”

## Visual QA

- No clipped text at 1.3x font scale.
- No content under status/navigation bars.
- No more than one dominant accent color per screen.
- Product imagery does not overpower recipient context.
- Exact amount is readable before approval.
- Error and unknown states feel first-class, not developer screens.
- Onboarding has one dominant focal point even when several supporting elements are present.
- Decorative elements do not overlap copy, progress or primary actions.
- Every primary flow is accepted only after rendered-device screenshots are inspected.
