# WishTrace Android Skill

Read design system, screen map, architecture and AGENTS.

Use immutable UI state and explicit events. Build one vertical route at a time. Include content/loading/error/recovery. Keep secrets out. Test custom tab/app-link return and process recreation. Use native Compose motion first. Validate 48dp targets, semantics, contrast and font scaling.

Do not add bottom navigation, settings or reusable architecture layers before the hero flow works.

Output: screens/states, changed files, build/test commands, device evidence, accessibility issues, remaining risk.
