# WishTrace Product Skill

Read `PLAN.md`, `docs/PRODUCT_SPEC.md`, `docs/DECISION_LOG.md` and integration status.

For every proposed feature:

1. Name the user problem.
2. Identify where it strengthens remember, discover, decide, purchase or proof.
3. Check Overall, UX, Visa, OpenAI and Localhost impact.
4. Reject generic chat, marketplace breadth, recipient adoption, pooled money and sponsor-only additions.
5. Prefer the smallest change visible in the flagship demo.
6. Record consequential changes.

Output: decision, user benefit, judging impact, scope cost, technical consequence, cut/fallback.
